# Stock Trends — 주식 비교

npm trends의 주식 버전. **국내·미국 주식과 ETF의 수익률을 한 차트에서 비교**합니다.
같은 금액을 넣었다면 지금 얼마가 됐을지, 최대 낙폭과 연평균 수익률까지 한 화면에서 확인합니다.

## 주요 기능

- **동일 투자금 정규화** — 같은 시점에 같은 금액을 넣었다고 가정하고 평가액 곡선을 겹칩니다
- **한국·미국 동시 비교** — 미국 종목은 **각 시점의 환율**로 원화 환산합니다. 총수익률을 주가·환율 기여분으로 분해해 보여줍니다
- **최대 5종목**, 조합이 같으면 색이 항상 같습니다
- **초성 검색** (`ㅅㅅㅈㅈ`), 종목코드·티커·영문명 모두 가능
- **상장일 자동 정렬** — 구간이 좁아지면 이유를 화면에 남깁니다
- **공유 URL** — `/삼성전자-vs-애플`. 별칭은 308로 정본에 모읍니다
- **건의사항 게시판** — 로그인 없이, 자동 생성 닉네임으로
- 다크모드, OG 이미지, 4,600여 페이지 사전 생성

## 구조

```
data/                       빌드 입력 (커밋, 배포 제외)
├── universe.json           2,153종목 — 사람이 읽고 편집하는 진실의 원천
├── us-etf-aliases.json
└── cache/                  환율 원본 · 심볼 해석 캐시
public/data/                산출물 (커밋 + CDN 배포)
├── meta.json               주차 그리드 + 환율
├── tickers.json            검색 목록
├── aliases.json            슬러그 별칭 (서버 전용)
├── popular-slugs.json      사전 생성 대상
├── kr/{종목코드}.json        원화 주간 종가
└── us/{티커}.json           달러 주간 종가
scripts/                    데이터 파이프라인 (.mjs)
src/                        Next.js 앱
tests/                      lib · integration · scripts
supabase/migrations/        게시판 스키마
```

## 실행

```bash
pnpm install
cp .env.local.example .env.local   # 비교 페이지는 값 없이도 동작합니다

pnpm dev
pnpm test        # 94건
pnpm build

pnpm data:all    # 환율 → 시세 → 슬러그 → 검증 (약 10초)
```

## 데이터

| 항목     | 내용                                                 |
| -------- | ---------------------------------------------------- |
| 시세     | 네이버 금융 (국내 `siseJson` / 해외 `chart/foreign`) |
| 환율     | 네이버 매매기준율 — 2004년~, API 키 불필요           |
| 해상도   | 주봉 (월봉은 중간 저점이 사라져 MDD가 얕게 나옴)     |
| 범위     | 한국 2000년~, 미국 대체로 2010년~                    |
| 수정주가 | 액면분할·증자 **보정됨**                             |
| 배당     | **미반영** — 국내 수정주가 표준                      |
| 갱신     | 주 1회, 완결된 주차만                                |

**조회 시점에 외부 API를 호출하지 않습니다.** 빌드 타임에 만든 정적 JSON만 읽고, 기간·투자금 조작은 전부 클라이언트 계산입니다. 전송량은 첫 로드 약 6KB + 종목당 2.5KB(gzip).

### 유니버스 2,153종목

한국 주식 1,155 · 우선주 27 · 리츠 18 · ETF 300 / 미국 주식 550(**S&P 500 전 종목**) · ETF 98

없는 종목은 검색 결과에서 요청할 수 있고, 종목코드나 티커면 **즉시 수신 가능 여부를 검증해 답합니다.** 중복 요청은 행이 아니라 득표로 쌓여 추가 우선순위가 됩니다.

## 자동화

| 워크플로               | 주기         | 내용                                        |
| ---------------------- | ------------ | ------------------------------------------- |
| `data-weekly.yml`      | 토 13:00 KST | 시세·환율 갱신 → 검증 → 변경 있을 때만 커밋 |
| `universe-monthly.yml` | 매월 1일     | 유니버스 재생성 → PR (자동 병합하지 않음)   |

`verify.mjs`를 통과해야 커밋합니다 — 성공률 95% 미만, 그리드 결손, 환율 구멍, 슬러그 충돌, 과거 구간 대량 재작성 중 하나라도 걸리면 멈춥니다.
